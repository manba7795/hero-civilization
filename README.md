# 英雄文明：万界六角纪元

这是从单文件网页原型升级后的正式工程骨架。

## 技术栈
- Vite
- TypeScript
- Three.js
- 数据驱动 JSON

## 运行
```bash
npm install
npm run dev
```

## 当前已落地
- Three.js 3D 六角地图基底
- 地形 / 高程 / 森林 / 山脉
- 可缩放、拖动、旋转摄像机
- Hex 点击选中
- 回合系统
- 城市系统骨架
- 固定国家领袖配置
- 自由英雄池
- 神器系统骨架
- 野生精灵刷新 / 捕获 / 伙伴绑定骨架
- 配置表拆分
- 美术资源目录与接入规范

## 下一开发里程碑
