# hero-civilization v0.5 开发记录

## 阶段1：核心玩法闭环

### 当前完成内容

- 地图存在并由 Three.js 渲染。
- 玩家单位由 GameState 管理。
- 初始玩家单位已存在：
  - 开拓者 settler
  - 战士 warrior
- 单位位置使用六角坐标 q/r 管理。
- WorldRenderer 根据游戏状态显示单位实体。
- 点击地图单位后进入选中状态。
- 选中后显示单位基础信息。
- 已支持选择目标六角格并移动单位。
- 结束回合按钮可推进回合。
- 回合推进会刷新单位移动力并更新游戏状态。
