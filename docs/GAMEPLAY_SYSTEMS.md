# v0.4 游戏系统说明

## 回合流程
1. 玩家移动、建城、战斗、英雄技能、捕获与城市操作。
2. 结束回合时，各城市结算粮食 / 生产 / 金币 / 科研 / 文化。
3. 满足人口阈值则城市成长；满足生产成本则创建单位。
4. AI 军队搜索最近的玩家城市 / 单位并移动、攻击或攻城。
5. 重置单位移动力、英雄技能状态，处理伙伴回血。
6. 根据概率刷新新的野生精灵。

## 城市
- 城市中心与一环地块根据人口数量参与收益。
- 国家固定领袖的国家加成叠加到城市收益。
- 当前生产物支持战士与开拓者。

## 英雄
- 英雄与国家解绑，从公共英雄池招募。
- 国家领袖固定且不进入英雄池。
- 英雄拥有基础 HP、攻击、移动、主动技能、3 个神器槽与 1 个精灵伙伴槽。

## 神器
- 通过城市开启神器宝箱三选一。
- 装备属性由数据表驱动，并实际参与 StatsSystem / CombatSystem。

## 野生精灵
- 按地形 / 地貌生态刷新。
- 有独立 HP 与攻击，攻击野生精灵时会发生反击。
- HP 越低捕获率越高；稀有度越高捕获率越低。
- 捕获后可绑定给英雄，提供被动属性。
