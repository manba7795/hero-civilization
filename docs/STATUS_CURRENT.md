# hero-civilization 当前状态报告

## 当前版本状态

当前仓库为《英雄文明：万界六角纪元》的正式工程骨架阶段。README 标识当前从单文件网页原型升级为正式工程，package.json 版本为 0.1.0。

## 项目技术情况

### 技术栈

- Vite
- TypeScript
- Three.js
- 数据驱动 JSON

### 启动方式

安装依赖：

```bash
npm install
```

开发启动：

```bash
npm run dev
```

其他可用脚本：

- npm run build
- npm run preview
- npm run typecheck

## 当前已有功能

根据 README 与项目结构确认，目前已有：

- Three.js 3D 六角地图基底
- 地形、高程、森林、山脉系统
- 摄像机缩放、拖动、旋转
- Hex 点击选中
- 回合系统
- 城市系统骨架
- 固定国家领袖配置
- 自由英雄池
- 神器系统骨架
- 野生精灵刷新、捕获、伙伴绑定骨架
- 配置表拆分
- 美术资源目录与接入规范

README 中还记录了正在推进的功能：

- A* 六角寻路
- 地形移动消耗
- 单位可达范围高亮
- 建城自动取得首圈领土
- 玩家/敌方领土颜色覆盖层

## 当前缺失功能

距离 v0.5 可玩版仍需要重点补齐：

- 完整地图连续化（海岸、河流、道路 Mesh）
- 单位系统完善
- 单位寻路与移动流程
- 战斗系统
- 建城完整玩法
- 英雄招募 UI
- 技能系统
- 神器选择与装备界面
- 精灵实体表现、削弱与捕获动画
- 存档系统
- AI 系统

## 当前目录结构说明

- src/core：核心逻辑相关代码
- src/data：数据配置相关代码
- src/game：游戏系统代码
- src/render：渲染相关代码
- src/ui：用户界面相关代码
- src/main.ts：程序入口
- src/styles.css：样式文件
- docs：项目文档、规则、路线和记录

## 下一阶段建议

下一阶段优先确认并实现最小可玩闭环：

1. 确认地图、单位、回合流程是否能形成基础游戏循环。
2. 补齐玩家控制单位移动能力。
3. 增加最基础交互反馈。
4. 避免提前扩展大型系统，先达到 v0.5 可运行版本。

## 主要风险

- 当前功能较多处于骨架阶段，需要避免系统扩散。
- 游戏核心循环尚需验证。
- 后续开发需要保持数据驱动结构，避免快速迭代导致架构混乱。
