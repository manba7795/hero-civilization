# hero-civilization v0.5

## 项目名称
hero-civilization v0.5

## 启动方式

开发环境：

```bash
npm install
npm run dev
```

构建试玩版本：

```bash
npm run build
npm run preview
```

## 当前功能

- 六角地图
- 玩家单位
- 单位选择
- 单位移动
- 玩家城市
- 城市资源
- 回合系统

## 已知问题

- 当前执行窗口无法直接运行本地 Node 环境，因此未在此环境完成 npm install / npm run build 实测。
- 需要用户本地环境进行最终浏览器试玩验证。
- 后续版本可继续扩展文明内容。
